# Ishwarya Goudagaon Portfolio

Personal portfolio website for Ishwarya Goudagaon.

## Run locally on Windows

1. Open the folder in VS Code.
2. Double-click `index.html`, or install the Live Server extension in VS Code.
3. Right-click `index.html` → **Open with Live Server**.

## Before publishing

Replace the `#` placeholders for LinkedIn, GitHub and project links in `index.html`.
